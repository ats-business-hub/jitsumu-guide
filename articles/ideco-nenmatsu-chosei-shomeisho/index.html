iDeCoの年末調整｜「小規模企業共済等掛金払込証明書」が届く人・届かない人と添付の要否

公開日（サイト原稿）：2026-11-26　記述の基準日：2026-11-26

広告について。本記事には広告（アフィリエイト）リンクは含まれません。控除の結果は保証しません。証明書の発送時期や記入欄は、iDeCo公式と勤務先の案内、国税庁の最新ページで確認してください。

iDeCo（個人型確定拠出年金）の掛金を年末調整で控除する手順を、国税庁タックスアンサーNo.1135（令和8年4月1日現在法令等）と、iDeCo公式サイト（国民年金基金連合会）のFAQ・ライブラリ・お知らせ（2026年11月26日に確認）から整理します。この記事に広告（アフィリエイト）リンクは含まれません。控除の結果は保証しません。

iDeCoの掛金は「小規模企業共済等掛金控除」の対象

No.1135では、小規模企業共済等掛金控除の対象に、確定拠出年金法に基づく個人型年金加入者掛金が含まれています。iDeCoはこの個人型年金です。控除額は、その年に支払った掛金の全額です。

手続きとして、支払った掛金の証明書（または電磁的記録印刷書面）を、年末調整で出す「給与所得者の保険料控除申告書」か確定申告書に添付するか、提出のときに提示する必要があります。申告先は、年末調整なら勤務先、確定申告なら所轄の税務署です。電磁的記録印刷書面とは、電子証明書等に記録された情報と、その内容を表す二次元バーコードが付いた出力書面のことです。

証明書が届く人・届かない人

証明書が届くかどうかは、職業よりも掛金の払い方で決まります。iDeCo公式FAQの内容は次のとおりです。

払込方法対象者の例小規模企業共済等掛金払込証明書
個人払込第1号加入者、第3号加入者、第2号加入者のうち個人払込を選んだ人国民年金基金連合会から届く
事業主払込第2号加入者のうち事業主払込を選んだ人発行されない

会社員でも、自分の口座から引き落とす個人払込なら証明書が届き、勤務先が給与から差し引いて納める事業主払込なら届きません。どちらを選んだか分からない場合は、加入時の書類や給与明細の控除欄を確認してください。

証明書はいつ、どこから届くか（令和8年分）

iDeCo公式のお知らせ（2026年10月1日付「令和8年分 小規模企業共済等掛金払込証明書の発行について」）では、令和8年分の控除証明書について、次のとおり案内されています。

  • 電子データは、令和8年10月21日から順次発行予定
  • ハガキの控除証明書は、令和8年10月23日発送予定
  • ハガキの対象は、令和8年中にiDeCoの払込実績があった方
  • 電子データでの交付を希望する場合は、別途申し込みが必要

公式ライブラリの「所得控除の手続き」では、ハガキと電子データは例年10月下旬に発行されると説明されています。10月発行分の金額は、当年1月から9月までに払い込まれた金額に、10月から12月の払込予定金額を加えたもの、とされています（払込月を指定している場合の扱いはライブラリの案内を見てください）。

初めての掛金の納付が10月以降の場合、FAQでは「納付月の翌月（本年11月から翌年1月）」に送付するとされています。ライブラリでは、この場合の発行は例年11月下旬、12月下旬、翌1月下旬、と案内されています。年末調整の提出期限に間に合わないことがあります。

住所変更や控除証明書の再発行を希望する場合、公式のお知らせとライブラリは、証明書に記載の受付金融機関（運営管理機関）に申し出るよう案内しています。お知らせでは、払込証明書のコール受付期間を令和8年10月19日から12月28日としています（平日9:00〜17:00。土日祝日、年末年始は利用不可）。

個人払込の人：年末調整での手順

公式ライブラリによると、年末調整では、ハガキに記載のある掛金の合計金額を「給与所得者の保険料控除申告書」の小規模企業共済等掛金控除（個人型年金加入者掛金）欄に記入し、証明書を添付します。電子データは、勤務先が電子データによる年末調整に対応している場合に利用できます。No.1135でも、証明書または電磁的記録印刷書面の添付または提示が必要です。

  1. 届いた「小規模企業共済等掛金払込証明書」（または電子データ）を用意する
  2. 「給与所得者の保険料控除申告書」の小規模企業共済等掛金控除（個人型年金加入者掛金）欄に、証明書の記載に沿って金額を書く
  3. 証明書を申告書に添付するか、提示する
  4. 勤務先が指定する期限までに提出する

記入欄の名前や位置は、勤務先が配る様式と記載例で確認してください。出し忘れたときの対応は年末調整の出し忘れ、記入ミスに気づいたときは年末調整の記入ミスにまとめています。

事業主払込の人：証明書がなくても控除される仕組み

事業主払込の場合、証明書は発行されません。iDeCo公式FAQでは、勤務先が毎月の給与から掛金を差し引き、その分を控除して源泉徴収税額を計算すると説明されています。年末調整は、毎月の源泉徴収で把握している納付済みの掛金額をもとに行われます。FAQには、年末調整時にまとめて精算（掛金の控除）をする取扱いはできない、とも書かれています。事業主払込の人は、毎月の給与計算の段階で控除が反映されているので、保険料控除申告書にこの証明書を添付する必要はありません。

年末調整に間に合わないとき：確定申告

証明書が年末調整に間に合わない場合（初回の掛金納付が10月以降の場合など）は、確定申告で控除を受けることになります。No.1135のとおり、確定申告書に証明書（または電磁的記録印刷書面）を添付するか、提出のときに提示します。年末調整と確定申告の違いは年末調整と確定申告の違い、還付申告の時期は還付申告は1月から出せるを見てください。

令和8年分の確定申告で使える「明細書」（年末調整には広げない）

No.1135には、令和8年分以後の所得税に係る確定申告書を令和9年1月1日以後に提出するときは、支払った掛金の証明書または電磁的記録印刷書面の添付または提示に代えて、一定の事項の記載がある明細書を確定申告書に添付できる、とあります。これは確定申告書についての取扱いです。年末調整の「給与所得者の保険料控除申告書」にこの取扱いを広げて書かないでください。年末調整では、これまでどおり証明書の添付または提示が必要です。

掛金額の設定と変更

iDeCo公式FAQでは、掛金は月に5,000円から拠出でき、掛金額の変更は1年（12月分の掛金から翌年11月分の掛金の間）に1回に限り行うことができる、とされています（企業型確定拠出年金の事業主掛金の額などが変動したことに伴う変更は、回数にカウントしない場合があります）。拠出限度額は加入者の区分や他制度の掛金額によって違うため、数字の表は公式の最新案内で確認してください。

提出前チェックリスト

  • 自分の払込方法が個人払込か事業主払込かを確認した
  • 個人払込の場合、令和8年分の証明書（ハガキまたは電子データ）が手元にある
  • 保険料控除申告書の「個人型年金加入者掛金」欄の金額が、証明書の合計と一致している
  • 個人払込の場合、証明書を添付または提示する準備をした
  • 初回納付が10月以降で証明書が間に合わない場合は、確定申告の準備をした

よくある質問

令和8年分のハガキはいつ発送されますか。 iDeCo公式のお知らせ（2026年10月1日付）では、ハガキは令和8年10月23日発送予定、電子データは同年10月21日から順次発行予定です。初回納付が10月以降の場合は、ライブラリの案内どおり例年11月下旬、12月下旬、翌1月下旬の発行になります。

証明書を紛失しました。 公式のお知らせとライブラリは、証明書に記載の受付金融機関（運営管理機関）に再発行を申し出るよう案内しています。

事業主払込なのに証明書が欲しいです。 FAQでは、事業主払込の加入者には証明書は発行されない、とされています。控除は毎月の源泉徴収と、それを踏まえた年末調整で反映されます。

確定申告では証明書の代わりに明細書を出せますか。 No.1135の「明細書で代えられる」は、令和9年1月1日以後に提出する令和8年分以後の確定申告書についての取扱いです。年末調整には適用しません。
