配偶者控除と配偶者特別控除の違い｜年末調整で迷わない「配偶者の合計所得金額」での判定【令和8年分】

結論：分かれ目は「配偶者の合計所得金額」

配偶者控除と配偶者特別控除のどちらに当たるかは、まず配偶者の年間の合計所得金額で決まります。そのうえで、控除を受ける本人（納税者）の合計所得金額によって控除額が変わります。

令和8年分の境界は次のとおりです。

  • 配偶者の合計所得金額が 62万円以下 → 配偶者控除の対象（出典: nta.go.jp ）
  • 配偶者の合計所得金額が 62万円超133万円以下 → 配偶者特別控除の対象（出典: nta.go.jp ）
  • 本人の合計所得金額が 1,000万円を超える → どちらも適用なし（出典: nta.go.jp / nta.go.jp ）

国税庁のタックスアンサーによれば、62万円の基準は令和8年12月1日に施行され、令和8年分から適用されます（出典: nta.go.jp ）。施行日前の源泉徴収や年末調整での適用関係については、同じページから国税庁のQ&A（令和8年5月）を見るよう案内されています。そのQ&A（国税庁「令和8年度税制改正（所得税の基礎控除の引上げ等関係）Q&A」（令和8年5月））では、令和8年11月までの給与の源泉徴収事務に変更はなく、令和8年12月に行う年末調整の際に1年間の税額を計算して精算するとされています。また、改正を反映した年末調整関係書類を、12月1日より前から提出することとしても差し支えないとされています。実際の提出日は勤務先の案内に従ってください。

この記事では「どちらに当たるか」を判断することに絞ります。年末調整全体のミスや出し忘れについては、令和8年分の年末調整で、落としやすい書き間違い と 年末調整の書類を出し忘れたとき を参照してください。

配偶者控除の要件と控除額（令和8年分）

要件

国税庁 No.1191 で確認できる主な要件は次のとおりです。

  • 配偶者の年間の合計所得金額が 62万円以下であること（令和8年分）。給与のみの場合は、給与収入 136万円以下が目安として示されています（出典: nta.go.jp ）
  • 本人の合計所得金額が 1,000万円以下であること（出典: 同上）
  • 民法の規定による婚姻に基づく配偶者であること。事実婚（内縁）の相手は対象外です（出典: nta.go.jp ）

生計を一にしていることや事業専従者でないことなど、ほかの要件も No.1191 本文で必ず確認してください。

「老人控除対象配偶者」は、控除対象配偶者のうち、その年12月31日現在の年齢が70歳以上の人をいいます（出典: nta.go.jp ）。

配偶者特別控除の要件と控除額（令和8年分）

要件

国税庁 No.1195 に挙げられている要件は次のとおりです（出典: nta.go.jp ）。

  • 本人の合計所得金額が 1,000万円以下
  • 配偶者の合計所得金額が 62万円超133万円以下（令和8年分）
  • 民法上の配偶者であること（内縁関係は不可）
  • 本人と生計を一にしていること
  • 青色申告者の事業専従者として給与を受けていないこと、または白色申告者の事業専従者でないこと
  • 配偶者自身が配偶者特別控除を受けていないこと（夫婦がお互いに受けることはできません）
  • 配偶者が、ほかの人の源泉控除対象配偶者として源泉徴収されていないこと（例外あり）

配偶者特別控除の上限（合計所得金額133万円）を給与収入に換算した目安は、No.1195 には書かれていません。この記事では換算額を載せません。配偶者に給与所得がある場合は、令和8年分は給与所得控除の最低保障額が65万円から74万円に引き上げられたので、改正後の給与所得控除額で計算した合計所得金額に応じて控除額を記載する必要がある、と国税庁Q&Aは案内しています（出典: nta.go.jp ）。

年末調整での判定手順（4ステップ）

ステップ1：本人の合計所得金額を見積もる 1,000万円を超える見込みなら、どちらの控除も受けられません（出典: nta.go.jp ）。本人の所得は、900万円以下・950万円以下・1,000万円以下のどの区分に入るかまで確認します。

ステップ2：配偶者の合計所得金額を見積もる 1月1日から12月31日までの1年分で見積もります。「年収」ではなく「合計所得金額」で判定する点に注意してください。給与のみの場合、配偶者控除の目安は給与収入136万円以下です（出典: 同上）。

ステップ3：62万円・133万円の境界に当てはめる 62万円以下なら配偶者控除、62万円超133万円以下なら配偶者特別控除です（出典: 同上 / nta.go.jp ）。

ステップ4：申告書に記入して勤務先へ提出する 令和8年分の年末調整では、「給与所得者の基礎控除申告書兼給与所得者の配偶者控除等申告書兼特定親族特別控除申告書兼所得金額調整控除申告書」を使います（出典: nta.go.jp ）。国税庁の「令和8年分 年末調整のしかた」には、令和8年分の配偶者控除額・配偶者特別控除額の一覧表が掲載されています（出典: 同上）。提出の締め切りは、勤務先の案内に従ってください。

扶養控除等（異動）申告書は、原則としてその年最初の給与を受ける日の前日までに給与の支払者へ提出します（出典: nta.go.jp ）。この申告書を出していないと、年末調整は行われません（出典: 同上）。

配偶者の「合計所得金額」に含めないもの

出産や育児休業の年は、配偶者に給付金が入っても所得に数えなくてよい場合があります。国税庁のQ&Aでは、次のものは合計所得金額に含めないとされています（出典: nta.go.jp ）。

  • 雇用保険の求職者給付
  • 出産育児一時金、出産手当金
  • 雇用保険の育児休業給付金（共済組合の育児休業給付金も同様）

年の途中で配偶者が亡くなった場合は、亡くなった時点の現況で判定し、所得は1月1日から死亡日までの分で見ます。月割計算はしません（出典: 同上）。

年末調整のあとで配偶者の所得が見込みと違ったら

年末調整は見積額で行うため、あとで配偶者の所得が確定すると区分が変わることがあります。申告書の訂正や再提出について、国税庁のFAQは勤務先の給与担当者に確認するよう案内しています（出典: nta.go.jp ）。

どの方法で直せるかは、時期や状況によって変わります。この記事では断定しないので、勤務先の給与担当者か税務署に確認してください。考え方は 年末調整の後に扶養や保険の変更に気づいたとき。再調整と確定申告 と 年末調整と確定申告の違い。会社員が両方必要になるとき、確定申告の窓口は国税庁「所得税の確定申告」（ nta.go.jp ）を参照してください。

注意：前の年分の基準と混ぜない

境界の金額は年分によって違います。配偶者控除の配偶者の所得要件は、令和7年分が58万円以下、令和2年分～令和6年分が48万円以下、令和元年分以前が38万円以下でした（出典: nta.go.jp ）。過去の年分の申告を直すときは、その年分の表を使ってください。逆に、令和8年分に昔の数字を当てはめないよう注意が必要です。

控除額は所得の見積もりや本人の事情によって変わります。本記事は判定の考え方をまとめたもので、特定の控除額や税額を保証するものではありません。

よくある質問（FAQ）

Q1. 配偶者の合計所得金額がちょうど62万円のときはどちらですか？ 「62万円以下」に入るため、配偶者控除の対象です（令和8年分。出典: nta.go.jp ）。

Q2. 事実婚のパートナーでも配偶者控除を受けられますか？ 受けられません。対象は民法の規定による婚姻に基づく配偶者です（出典: nta.go.jp ）。

Q3. 配偶者が産休中に出産手当金や出産育児一時金を受け取りました。所得に含めますか？ 含めません（出典: 同上）。

Q4. 夫婦それぞれが相手を配偶者特別控除の対象にできますか？ できません。夫婦の間でお互いに受けることはできないとされています（出典: nta.go.jp ）。

Q5. 本人の所得が1,000万円をわずかに超えそうです。 1,000万円を超えると、どちらの控除も適用されません（出典: nta.go.jp ）。見積もりは勤務先の担当者にも確認してください。
