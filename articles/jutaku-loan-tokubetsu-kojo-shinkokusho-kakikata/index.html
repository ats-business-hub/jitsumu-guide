確定申告・税金

住宅借入金等特別控除申告書の書き方｜2年目以降の年末調整

公開日（サイト原稿）：2026-11-27　記述の基準日：2026-11-27

広告（PR）について。本記事には、A8.net、バリューコマースなどのアフィリエイト（成果報酬型広告）リンクが含まれます。リンク経由で申し込みや利用があった場合、運営者が紹介料を受け取ることがあります。リンクはテキストのみです。就職、収入、税負担の軽減、投資の利益、最安値などを保証するものではありません。各サービスの対象条件・成果地点・料金は、申し込み前に公式ページで確認してください。

用紙はいつ・どう届く？使うのは「令和8年分」の1枚

住宅借入金等特別控除（住宅ローン控除）は、最初の年分は確定申告で適用を受けます。2年目以降は年末調整で適用を受けられます（国税庁「給与所得者（従業員）の方へ（令和８年分）」）。申告書は、税務署から従業員本人に交付されます（同ページ）。

届く時期は、方式と交付方法によって次のように異なります（国税庁「給与所得者（従業員）の方へ（令和８年分）」）。

方式・交付方法 時期
証明書方式・電子交付 毎年10月頃、e-Taxメッセージボックスに格納
証明書方式・書面 入居2年目の10月下旬頃に送付
調書方式・電子交付 毎年11月中旬頃、e-Taxメッセージボックスに格納
調書方式・書面 入居2年目の11月下旬頃に送付

書面の場合は、控除を受ける各年分の申告書がまとめて送られてきます（同ページ）。そのため、手元には複数年分の用紙があるはずです。今年の年末調整で使うのは、「令和8年分」と印字された用紙です。ほかの年分の用紙を代わりに使ったり、令和7年分の手引きを令和8年分に当てはめたりしないでください。

証明書方式と調書方式の違いや、それぞれの必要書類は 住宅ローン控除の2年目以降。年末残高証明書と調書方式の確認 で詳しく説明しています。この記事では欄の書き方に絞ります。

書き始める前に手元にそろえるもの

  • 「年末調整のための（特定増改築等）住宅借入金等特別控除証明書兼給与所得者の（特定増改築等）住宅借入金等特別控除申告書」（令和8年分）（国税庁 No.1211-1、No.1212、いずれも令和8年4月1日現在法令等）
  • 証明書方式の場合： 金融機関等の「年末残高等証明書」。各年の11月下旬頃に送付されます。借入先が複数ある場合は、すべての証明書を提出します（年末調整で住宅借入金等特別控除を受ける方へ（令和7年居住者用））。
  • 調書方式の場合： 金融機関から年末残高等証明書は交付されないため、提出は不要です（同PDF）。
  • 用紙と一緒に入っていた説明書。令和7年居住者用の説明書は「令和9年分以後も使用する」ので保存しておくよう書かれています（同PDF）。

手引きの年版に注意： 国税庁の特設ページ（年末調整で住宅借入金等特別控除の適用を受ける方へ）は、令和7年分の確定申告で控除を受けた方が令和8年分以降の年末調整で使うための案内です。令和6年以前に入居した方は、自分の用紙に同封された説明書を使ってください。国税庁の従業員向けページには、令和8年分の年末調整用の記載例（記載例PDF）へのリンクもあります。この記載例の「記載例1」は、平成30年分に確定申告で控除を受けた人が令和8年分を年末調整で受ける場合の例で、連帯債務がある場合を説明しています（国税庁「給与所得者（従業員）の方へ（令和８年分）」、記載例PDF）。勤務先向けの「令和8年分 年末調整のしかた」には、「2-4 住宅借入金等特別控除申告書」と「住宅借入金等特別控除申告書の記載例」が掲載されています（令和8年分 年末調整のしかた）。

申告書の記入順（公式記載例に沿って）

国税庁は、令和7年居住者向けに4種類の記載例を公開しています（国税庁「年末調整で住宅借入金等特別控除の適用を受ける方へ」）。自分のケースに近いものを選び、並べて見ながら書くのが確実です。

  • 例①：新築住宅（省エネ基準適合住宅）と土地の借入を別々に実施、連帯債務なし（国税庁 住宅借入金等特別控除 記載例①（PDF））
  • 例②：中古住宅と土地の借入を一緒に実施、連帯債務あり（02.pdf）
  • 例③：中古住宅と土地の借入の後に増改築の借入を実施、連帯債務なし（03.pdf）
  • 例④：調書方式に対応する金融機関から新築住宅と土地の借入を別々に実施、連帯債務なし（05.pdf）

記入の流れは次のとおりです。

  1. 所轄税務署長の欄： 給与の支払者（勤務先）の所在地等を所轄する税務署長を書きます（説明書（令和7年居住者用））。
  2. 勤務先・本人の欄： 記載例の書き方に合わせて記入します（国税庁 住宅借入金等特別控除 記載例①（PDF））。
  3. 年末残高の欄： - 証明書方式の場合は、年末残高等証明書の金額を転記します。 - 調書方式の場合は、控除証明書の「住宅借入金等の年末残高に関する事項」欄から転記します。この欄が空欄なら、住宅ローン返済計画表などをもとに書きます（05.pdf）。 - 調書方式で控除見込額が印字されていても、繰上返済などで実際の年末残高と違う場合は、実際の残高で計算し直します（国税庁「年末調整で住宅借入金等特別控除の適用を受ける方へ」手引き（PDF））。説明書ではこの年末残高欄を「ワ、カ、ヨ欄」としています（同PDF）。
  4. 住宅と土地を別々に借りている場合： 例①では、2本の借入の年末残高（13,000,000円と15,000,000円）を合計して28,000,000円としています（国税庁 住宅借入金等特別控除 記載例①（PDF））。
  5. 備考欄： - 調書方式の場合は「調書方式に対応する金融機関からの借入れ」などと書きます。 - 災害で被害を受けた場合は「災害発生日」を書きます（国税庁「年末調整で住宅借入金等特別控除の適用を受ける方へ」手引き（PDF））。
  6. 重複適用の場合： 重複適用1枚目・2枚目の控除額欄の金額を合計して記入します（同PDF）。増改築の借入を追加した場合の書き方は、例③の記載例（03.pdf）と説明書で確認してください。

各欄の正式な名前と番号は年分や様式によって違うことがあります。必ず手元の用紙の表記を優先してください。

連帯債務・居住用割合・持分がある場合

  • 単独所有の例： 例①では、居住用割合を100.0%、持分を100.00%としています（国税庁 住宅借入金等特別控除 記載例①（PDF））。
  • 連帯債務の例： 連帯債務がある場合は、例②の記載例（02.pdf）と、令和8年分の記載例1（記載例PDF）が該当します。連帯債務者の書き方や、自分の負担分の計算は、手元の用紙と記載例の注意書きに沿って記入してください。この記事では、記載例の数字から計算方法を推し量ることはしません。
  • 店舗兼住宅などで居住用割合が100%でない場合は、この記事では扱いません。用紙の該当欄の指示と、同封の説明書に従ってください。

控除額の計算は「用紙に印字された算式」どおりに

  • 令和4年以降に入居した場合、控除額は年末残高等×0.7%で計算し、100円未満は切り捨てます（国税庁 No.1211-1）。記載例の用紙にも「⑤×0.7％」という算式が印字されています（国税庁 住宅借入金等特別控除 記載例①（PDF））。
  • 控除限度額は、入居年と住宅の区分によって違います。たとえば省エネ基準適合住宅で令和6・7年に入居した場合は、控除期間13年・限度額21万円です（子育て世帯などの特例対象個人は28万円。国税庁 No.1211-1）。令和3年までに入居した場合は、年末残高等の1%など、異なるルールです（国税庁 No.1212）。
  • 自分で率を選んだり計算式を組み立てたりせず、届いた令和8年分の用紙に印字された算式と限度額に従うのが安全です。
  • 勤務先は、控除額が算出所得税額を超えていないかを確認します。控除しきれない場合は、源泉徴収票の「住宅借入金等特別控除可能額」欄に記入されます（国税庁 年末調整のしかた（住宅借入金等特別控除））。

この記事は控除額や還付額を保証するものではありません。記入を間違えた場合の直し方は 令和8年分の年末調整で、落としやすい書き間違い を参照してください。

申告書をなくしたとき（交付申請）

申告書をなくした場合は、税務署に交付申請をして再交付を受けます。手続の名前は「年末調整のための（特定増改築等）住宅借入金等特別控除関係書類の交付申請手続」です（国税庁の手続ページ）。従業員向け案内（国税庁「給与所得者（従業員）の方へ（令和８年分）」）から同じページにリンクされています。手続番号は2つのページで表記が違うため、この記事では手続の名前で案内します。

  • 提出時期： 特に定められていません。ただし、関係書類は交付申請手続をした後の年分について送付されます（国税庁の交付申請手続ページ）。
  • 提出方法： e-Taxで提出するか、書面を持参・郵送します。代理人が窓口で請求する場合は委任状が必要です（同ページ）。
  • 提出先： 納税地を所轄する税務署長です（同ページ）。
  • 届くまでの日数は手続ページに書かれていないため、年末調整の締切が近い場合は早めに申請し、勤務先にも伝えてください。年末調整に間に合わない場合の扱いは 年末調整と確定申告の違い。会社員が両方必要になるとき と 年末調整の書類を出し忘れたとき で扱います。

ふるさと納税と住宅ローン控除を併用する場合の考え方は ふるさと納税と住宅ローン控除は併用できるか を、地震保険料控除の証明書をなくした場合は 地震保険料控除証明書をなくしたら｜年末調整に間に合わせる再発行・電子交付の方法 を参照してください。

広告（PR）。個人向けのクラウド会計・確定申告ソフトの一例として、マネーフォワード クラウド確定申告、freee会計、やよいの白色申告オンライン／やよいの青色申告オンラインがあります。推奨ではありません。対象は個人です。ソフトは必須ではなく、国税庁の確定申告書等作成コーナーでも申告できます。料金プランや対応機能は公式案内で確認してください。申告の受理、還付や節税は保証しません。最新の手数料・条件は公式サイトでご確認ください。

よくある質問

Q1. 同じ封筒に何年分も入っていました。全部提出しますか？ 書面の場合、各年分の申告書がまとめて送られてきます（国税庁「給与所得者（従業員）の方へ（令和８年分）」）。年末調整で提出するのはその年分の1枚です。残りは翌年以降に使うため保管してください。

Q2. 調書方式なのに、年末残高等証明書を待つ必要はありますか？ 調書方式では金融機関から証明書が交付されないため、提出は不要です（国税庁「年末調整で住宅借入金等特別控除の適用を受ける方へ」手引き（PDF））。

Q3. 印字された控除見込額をそのまま書いてよいですか？ 繰上返済などで実際の年末残高と違う場合は、実際の残高で計算し直します（国税庁「年末調整で住宅借入金等特別控除の適用を受ける方へ」手引き（PDF）、05.pdf）。

Q4. 借入先が2つあります。 証明書方式の場合は、すべての年末残高等証明書を提出します（国税庁「年末調整で住宅借入金等特別控除の適用を受ける方へ」手引き（PDF））。記入の仕方は例①（国税庁 住宅借入金等特別控除 記載例①（PDF））が参考になります。
