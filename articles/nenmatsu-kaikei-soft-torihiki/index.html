確定申告・税金

年末までに会計ソフトへ取引を入れる順番と、確定申告前の料金プラン確認

公開日（サイト原稿）：2026-11-21　更新日：2026-11-28　記述の基準日：2026-11-28

暦年（1月1日から12月31日）で収支を見る個人事業主や副業の人は、年末までに請求、経費、口座の動きをそろえておくと、確定申告の時期に慌てにくくなります。本記事は、どのソフトが良いかを決めるものではありません。年末までに取引を入れる順番と、申告前に料金プランとデータの出し入れを確認する観点の整理です。帳簿が正しく終わること、申告が通ること、還付や節税は保証しません。税務の判断は、国税庁の案内と、必要なら税理士の確認を優先してください。

帳簿をほとんど付けないまま年末になった人向けの「さかのぼって入力する順番」は、この記事の後半の節にあります。クラウドソフトを使う前に決めることは個人事業主・副業の確定申告で、クラウドソフトを使う前に決めること、ソフトを比較する前に見る点は個人事業主向け。freee・弥生・マネーフォワードを比較する前に見る点、会社員が年末調整と確定申告の両方を考えるときは年末調整と確定申告の違い。会社員が両方必要になるときを見てください。経費の考え方は副業・在宅ワークで経費にできるものの考え方（一覧と家事按分）にあります。前半は、年をまたぐ前の作業順の話です。

年末までにそろえておく取引

次の順序は一例です。業種や申告の種類で、必要な書類は違います。期限の一般則や金額は、この記事では書きません。

  1. 今年の取引に使う口座、カード、現金の範囲を決める。 プライベートとの混在がある場合は、後から分ける根拠を残します。分ける方法の適否は、当サイトでは判断しません。
  2. 請求書、領収書、支払通知、仕入の記録を、日付順に揃える。 年末時点で未入金の請求、未払いの経費がある場合の扱いは、会計の区分（発生主義か、現金主義かなど）と、自分の申告方法で違います。ソフトの初期設定は、先に公式の説明で確認してください。
  3. 口座やカードの明細を取り込む、または入力する。 自動連携がある場合でも、漏れと重複は自分で照合します。連携が成功することは保証しません。
  4. 経費の科目と、事業割合が必要なものを見直す。 科目の正しさは保証しません。判断に迷うものは、国税庁の案内を先に見てください。
  5. 今年中の寄附（ふるさと納税を含む）、医療費、保険料など、申告で使う可能性のある記録を別途保管する。 控除の可否と上限は、この記事では計算しません。

ソフトに入れ終わることと、申告書の提出は別です。提出期限と送信結果は、自分で確認してください。

帳簿をほとんど付けないまま年末になったとき：1年分をさかのぼって入力する順番

「副業の収入はあるが、帳簿はほとんど付けていない」と12月に気づいたときの、1年分を会計ソフトへさかのぼって入れる順番の整理です。対象は会社員の副業を想定しています。手順の整理であり、税額や「この方法なら間に合う」といった保証はしません。個別の判断が必要なときは、税務署や税理士に確認してください。

1. まず、確定申告が必要かを確認する

国税庁タックスアンサーNo.2020「確定申告」は、給与の収入金額が2,000万円以下で、給与を1か所から受けていて、その給与の全部について源泉徴収される人で、給与所得および退職所得以外の所得金額が20万円以下の人などは、一定の場合に確定申告をしなくてもよい、と案内しています。自分が当てはまるかは、国税庁「所得税の確定申告」と副業20万円の記事で確認してください。所得税の申告が不要でも、住民税は別に確認が必要です（副業と住民税）。

申告期間は、No.2020では「原則として、その年の翌年2月16日から3月15日まで」です。令和8年分の確定申告書の受付期間は、国税庁の令和9年2月広報で、令和9年2月16日（火）から3月15日（月）までと案内されています（2026年11月28日確認）。年末調整の出し忘れで確定申告になる場合は年末調整の書類を出し忘れたときと年末調整と確定申告の違いを見てください。

2. 青色申告か白色申告かを確認する

さかのぼって入力する前に、どちらで申告するかを決めます。制度と特別控除は、国税庁のNo.2070「青色申告制度」とNo.2072「青色申告特別控除」で確認できます。承認申請の期限と控除の条件は、令和8年分に当てはまるかを含めて、公式ページで確認してください。当サイトの整理は青色申告特別控除65万円の条件と開業届のメリットとデメリットにあります。どちらで申告するかで、作る書類（青色申告決算書か収支内訳書か）と、選ぶプランが変わります。

3. 入力する前に「材料」を1か所に集める

さかのぼって入力するときに時間がかかるのは、入力よりも材料探しです。先に次を集めます。

材料何に使うか
副業の売上が入る銀行口座の明細（1〜12月分）売上の入力、入金の確認
副業の経費に使ったクレジットカードの明細経費の入力
レシート・領収書（紙・電子）経費の根拠
取引先からの請求書・支払明細売上の金額と日付の確認
本業の源泉徴収票（年明けに受け取るもの）確定申告書の作成

経費にできる範囲の考え方は副業・在宅ワークで経費にできるものの考え方にまとめています。

4. 会計ソフトを選ぶ：見るのは「さかのぼって入れやすいか」

1年分を後から入力するなら、日々の記帳のしやすさよりも次の点を公式で見ておくと、選び直しの手間を減らせます。どのソフトがどこまで対応しているかは、この記事では断定しません。

  • 口座やカードの明細を取り込めるか。過去の明細をどこまでさかのぼれるかは、金融機関とソフトで違います（口座・カード連携の確認点）。
  • 連携できない口座の明細を、CSVなどで取り込めるか。対応する形式は各社の公式案内で確認します。
  • 白色・青色のどちらの書類を作れるか、そのためのプランはどれか。
  • 申告書をe-Taxで送信するまでの流れに対応しているか。

料金とプランは各社の公式ページで確認してください。この記事では金額を書きません。参考として、マネーフォワード クラウド確定申告の料金ページには「2026年12月に料金体系の一部改定を予定」との表示があります（2026年11月28日確認）。申し込み前に最新の表示を見てください。3社の違いはfreee・弥生・マネーフォワードを比較する前に見る点で整理しています。

広告（PR）。 1年分をさかのぼって入力する場合の、個人向けのクラウド会計・確定申告ソフトの一例として、マネーフォワード クラウド確定申告、freee会計、やよいの白色申告オンライン／やよいの青色申告オンラインがあります。推奨ではありません。ソフトは必須ではなく、国税庁の確定申告書等作成コーナーでも申告できます。帳簿の完成、申告の受理、還付や節税は保証しません。最新の手数料・条件は公式サイトでご確認ください。

5. さかのぼって入力するときの順番

  1. 事業用の口座・カードを登録する。 副業専用の口座やカードがあれば先に登録します。私用と兼用の場合は、事業分だけを拾う作業が後で必要になります。
  2. 売上を先にすべて入れる。 売上は件数が少ないことが多く、請求書や入金明細と照らし合わせやすいので、先に確定させます。年をまたいで入金される売上の扱いは年末の締めで迷う売掛金・未払いを見てください。
  3. 金額の大きい経費から入れる。 パソコンや機材など高額なものは、一度に経費にできず減価償却になる場合があります。区分は年末の減価償却の区分で確認してください。
  4. 毎月の固定費（通信費・サブスクなど）を入れる。 ソフトに繰り返し入力などの機能があれば、使うと早く済みます。機能の有無はソフトごとに公式で確認します。
  5. 少額の経費（レシート類）を最後に入れる。 件数が多いので最後にまとめて入れます。
  6. 私用と兼用の支出は、按分の考え方を決めてから入れる。 自宅の通信費などを事業と私用で分けるときは、按分の考え方を先に決めておきます。
  7. 12月末時点の口座残高と、ソフト上の残高を照らし合わせる。 合わないときは、売上・経費の漏れと重複から見直します。

6. 12月中にやっておくと楽になること

  • 1〜11月分の明細をダウンロードしておく。金融機関によって、過去の明細を見られる期間に限りがあります。
  • 紙のレシートを月ごとに封筒に分けておく。
  • 年明けに届く源泉徴収票の受け取り方法を、勤務先に確認しておく。
  • e-Taxで提出するなら、事前に必要な準備を確認しておく（確定申告をスマホで進める手順、e-Tax（個人））。

提出前の書類チェックは令和8年分の確定申告に向け、12月から集める書類のチェックリストにまとめています。

確定申告前に、料金プランで確認すること

ソフトの比較軸（申告の種類、消費税、サポート、データの出し入れ）は個人事業主向け。freee・弥生・マネーフォワードを比較する前に見る点で整理しています。年をまたぐ前に、次を公式で見ておくと、申告時期のプラン変更に慌てにくくなります。

  • いまのプランで、自分の申告種類（白色・青色、消費税の有無）に必要な機能が含まれるか。 白と青で商品が分かれていることがあります。
  • 無料期間やキャンペーンの終了時期。 終了後の月額または年額、申告書の作成・提出機能がどのプランに含まれるか。金額はこの記事では書きません。
  • 年払いと月払い、初年度と翌年の違い。 「今だけ」の表示を、翌年の条件と分けて見てください。
  • データの書き出し。 乗り換える場合や、自分で控えを残す場合に、仕訳や明細を出せるか。形式と手順は公式で確認します。書き出せることは保証しません。
  • サポートの範囲と、確定申告期の受付時間。 チャット、電話、仕訳相談の可否はプランで違うことがあります。税務判断までは対象外のことがあります。

ソフトは必須ではありません。国税庁の確定申告書等作成コーナーとe-Taxでも申告できます。作成コーナーを使う場合でも、日々の記録は別に必要です。

申し込みやプラン変更を急がない方がよい場合

  • 白色か青色か、消費税の申告が要るかを決めていない
  • 無料期間の終了日と、申告に必要な機能の有無を確認していない
  • 年をまたいだあとに、今年の取引を一括で入れようとして、明細が揃っていない
  • 料金の安さだけで選び、データの書き出しを見ていない

操作感は、体験や無料期間で、自分の口座連携と仕訳の量で試す方法があります。体験でうまくいっても、本番の申告が正しく終わることは保証できません。

チェックリスト

  • 今年使う口座・カードと、請求・領収の記録を揃えた
  • 明細の取込または入力と、漏れ・重複の照合をした
  • 自分の申告種類に必要な機能が、どのプランに含まれるかを公式で確認した
  • 無料期間やキャンペーンの終了後の条件を見た
  • データの書き出し方法を確認した
  • 提出はソフト任せにせず、期限と送信結果を自分で確認する順にした

よくある質問

年末までにソフトへ入れ終えれば、確定申告は終わりますか。

終わりません。申告書の作成、添付や送信、控えの保存が残ります。期限は国税庁の案内を見てください。完了は保証しません。

いちばん安いプランはどれですか。

この記事では金額を示しません。税込と税抜、年払い、キャンペーン、申告種類で並びが変わることがあるためです。最新の手数料・条件は公式サイトでご確認ください。

取引の入力が年明けになってもよいですか。

入力作業そのものの期限は、ソフトの利用規約とは別に、申告と帳簿の保存のルールで見ます。遅くなった場合のリスクは、この記事では断定しません。記録の根拠（明細や領収）は、入力の前から保管してください。
